Get Your Realtek WiFi Working on Linux

One command installs RTW88 WiFi 5 drivers with DKMS - so they survive every kernel update.

DKMS Support Secure Boot Ready Multi-Distro GitHub

Quick Install

Run this in your terminal as your normal user (not with sudo). It detects your distro and installs everything the driver needs:

bash
/bin/bash -c "$(curl -fsSL https://dandanilyuk.github.io/rtw88_driver_installer/install.sh)"

The script asks for your sudo password and only touches driver-related files. To preview every step without changing anything, add -- --dry-run to the end of the command. To uninstall, add -- -u instead.

What the Script Does

  1. 1

    Detect Your System

    Identifies your distro (Debian, Ubuntu, Kali, Arch, etc.), looks for your Realtek adapter, and installs kernel headers and build tools.

  2. 2

    Fetch the Latest Drivers

    Pulls the lwfinger/rtw88 source - a community-maintained backport of the upstream kernel drivers.

  3. 3

    Build & Register with DKMS

    Compiles the driver for your running kernel and registers it with DKMS so it rebuilds automatically on every kernel update.

  4. 4

    Install Firmware & Config

    Copies the firmware files and a modprobe config that switches off the kernel's built-in rtw88 driver. A reboot loads the new one.

What Gets Installed

Driver Source

lwfinger/rtw88 - community-maintained backport of the upstream Realtek WiFi 5 drivers

Installation Method

DKMS - the driver rebuilds itself automatically every time your kernel updates

Dependencies

build-essential (or base-devel), dkms, git, and your kernel headers - installed automatically

Configuration

Firmware files, plus a modprobe config with sensible defaults that keeps the in-kernel driver from loading

After Installation

A few things to check once the script finishes:

  1. 1. Handle Secure Boot

    With Secure Boot on, you may need to enroll a Machine Owner Key (MOK). The script checks and prints the exact steps if you do.

  2. 2. Reboot

    A reboot loads the new driver. Your WiFi adapter should appear automatically.

  3. 3. Verify

    Confirm the driver loaded: lsmod | grep rtw
